# EV charging session energy prediction

This artifact accompanies a study of arrival-time prediction using completed-session history.

- Start with REPRODUCE.md for the environment, data provenance, and verification commands.
- The notebook walks through data checks, feature construction, and evaluation. Open it from the extracted project directory for local execution.
- Saved models and predictions are under analysis_outputs. Default notebook execution verifies cached results without refitting models.
- DATA_SOURCES.md gives the original dataset citation and license.
