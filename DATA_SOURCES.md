A dataset for multi-faceted analysis of electric vehicle charging transactions.
Figshare, version 1. https://doi.org/10.6084/m9.figshare.22495141.v1
Dataset licence: Creative Commons Attribution 4.0 (CC BY 4.0).
Retain attribution when redistributing the data.

Associated descriptor: Baek, K.; Lee, E.; Kim, J. (2024).
A dataset for multi-faceted analysis of electric vehicle charging transactions.
Scientific Data 11, 262. https://doi.org/10.1038/s41597-024-02942-9
Author order differs between the dataset and the paper.

The supplied workbook is copied as received; the canonical CSV is inherited from the
previous research package. verification/source_equivalence.json records comparison results.
The quarantine CSV is an audited subset of the same source, not a second dataset.
Third-party Python dependencies retain their respective licences. No new licence for
the group's research code is assigned by this packaging operation.
